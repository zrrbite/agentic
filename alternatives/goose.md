# Goose

## TL;DR

Apache-2.0 open-source general-purpose agent from **Block** (Square/Cash App). Rust-built, ships as both desktop app and CLI, with 70+ MCP extensions and 15+ LLM providers. Goes beyond code — research, automation, data analysis. Part of Linux Foundation's Agentic AI Foundation.

## Specs

- **License**: Apache 2.0
- **Architecture**: Native desktop app (macOS/Linux/Windows) + full CLI + embeddable API
- **Language**: Rust
- **Governance**: Linux Foundation's Agentic AI Foundation

## Extensibility

- **MCP** — first-class, 70+ official extensions
- **Multi-provider** — Anthropic, OpenAI, Google, Ollama, OpenRouter, Azure, Bedrock, etc.
- **Recipes** — reusable workflow templates (rough analogue to CC skills)
- **Sessions** — persistent agent state
- **Whitelabeling** — custom distribution with preconfigured providers
- **ACP compatibility** — can act as an agent backend for editors like Zed

## vs Claude Code

- **General-purpose, not coding-specific** — broader scope than CC
- **Desktop GUI + CLI parity** — CC has no first-party desktop app
- **Recipes provide reusable workflow templates** — rough analogue to CC skills, oriented around multi-step tasks
