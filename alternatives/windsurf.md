# Windsurf

> ⚠️ **Partially unverified** — windsurf.com/docs.windsurf.com blocked WebFetch during research. Draws on publicly known positioning as of 2026-04-10.

## TL;DR

Proprietary AI-first IDE (VS Code fork) originally from Codeium, now owned by **Cognition** (acquired 2025 after Google talent deal collapsed). Known for "Cascade" agentic flows and Supercomplete autocomplete.

## Specs

- **License**: Proprietary (commercial); VS Code MIT base
- **Architecture**: Desktop IDE fork of VS Code (macOS/Windows/Linux)
- **No public source repo**

## Extensibility

- **MCP** — supported in Cascade agent
- **VS Code extension ecosystem** — inherited
- **Custom rules/memories**
- **No public plugin SDK** analogous to CC hooks

## Signature features

- **Supercomplete** — inline autocomplete
- **Cascade Flows** — chain editor actions with agent steps

## vs Claude Code

- **Full IDE product with inline autocomplete** (Supercomplete) — CC is just the agent loop
- **Cascade "Flows"** chain editor actions with agent steps — a tighter editor/agent coupling than CC achieves from the terminal
- **Closed-source and subscription-based** vs CC's API-usage model
