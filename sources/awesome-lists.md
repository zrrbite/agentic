# Awesome Lists

Curated GitHub awesome-* repos relevant to Claude Code, MCP, and agentic coding.

## Direct relevance to Claude Code

- [hesreallyhim/awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code) — Curated list of skills, agents, plugins, hooks, and slash commands for CC workflows (~37.8k stars). **The canonical starting point.**
- [punkpeye/awesome-mcp-servers](https://github.com/punkpeye/awesome-mcp-servers) — Curated MCP servers across DB, cloud, dev, finance, etc. (~84.5k stars)

## Broader agent / LLM ecosystem

- [e2b-dev/awesome-ai-agents](https://github.com/e2b-dev/awesome-ai-agents) — Curated autonomous AI agents (open + closed source), maintained by E2B
- [Shubhamsaboo/awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps) — 100k+ star collection of LLM apps using RAG, agents, MCP, voice agents across OpenAI/Anthropic/Google/xAI/OSS models

## Gotcha

- `awesome-claudecode` (no hyphen) — **does not exist**. The canonical one is hyphenated (`awesome-claude-code`).
