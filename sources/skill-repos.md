# Public Skill Repos

Public GitHub repos that collect Claude Code skills.

## Canonical

- [obra/superpowers](https://github.com/obra/superpowers) — Complete dev workflow for coding agents built on composable "skills" (TDD, code review, brainstorming, executing-plans, systematic-debugging, verification-before-completion, etc.). ~144k stars. Install: `/plugin install superpowers@claude-plugins-official`.

## Large collections

- [wshobson/agents](https://github.com/wshobson/agents) — 149 agent skills alongside agents, orchestrators, and commands

## Aggregators

- [hesreallyhim/awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code) — Has a dedicated skills section aggregating community skill repos

## Notes

- Skills are a relatively new surface in CC — expect this list to grow
- Not all community skills are packaged as plugins; some are loose `.claude/skills/` directories meant to be copied
