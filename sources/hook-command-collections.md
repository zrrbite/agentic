# Hook & Slash Command Collections

Community-maintained repos of Claude Code hooks and slash commands.

## Hooks

- [disler/claude-code-hooks-mastery](https://github.com/disler/claude-code-hooks-mastery) — Reference implementation covering all 13 hook lifecycle events with Python/UV examples: prompt validation, TTS notifications, security blocks, sub-agents, meta-agent. **The best learning resource for hooks.**

## Slash commands

- [wshobson/commands](https://github.com/wshobson/commands) — Production-ready slash commands with automation and multi-agent orchestration
- [wshobson/agents](https://github.com/wshobson/agents) — Also contains 96 slash commands as part of its plugin bundle

## Aggregators

- [hesreallyhim/awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code) — Aggregates hooks and slash-command collections as sub-sections
