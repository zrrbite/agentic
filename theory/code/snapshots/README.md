## What's *not* in these snapshots

- The 08 notebook has no executed model outputs — it needs a GPU. Run it in Colab via the badge at the top of the file
- These are static markdown — interactive cells, kernel state, and editable code are only available when you open the actual `.ipynb` files locally

## Refreshing

Snapshots are auto-updated by CI on push to `main`. To regenerate locally:

```bash
cd theory/code
python render-snapshots.py            # all
python render-snapshots.py 06-*.ipynb # one
```

For just a fast smoke-test (parse + Python-syntax-check, no execution):

```bash
python check-notebooks.py
```
