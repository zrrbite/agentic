# Experiments

Hands-on notes from trying things. Keep it loose — date the file, dump what happened, move on.

## Format

- Filename: `YYYY-MM-DD-<short-topic>.md`
- Start with **what I was trying to do**
- Then **what I actually did** (commands, configs)
- Then **what happened** (worked / broke / surprising)
- Then **what I'd try next**
